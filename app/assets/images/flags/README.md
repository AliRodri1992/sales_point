# Local SVG country flags

All 249 ISO 3166-1 alpha-2 flags are bundled locally from [flag-icons](https://github.com/lipis/flag-icons), licensed under MIT (see LICENSE.flag-icons).

Source collection: `flags/4x3/*.svg`. These tracked SVG assets require no CDN or build-time flag downloads. Country selectors use the Rails asset pipeline to resolve fingerprinted URLs. This is purely presentation data.
